### Weather, translated into decisions

**OUTSIDE** is a monochrome Android weather assistant that converts forecasts into a personal comfort index and five prioritized recommendations.

- 🧠 Personal **0–100 comfort index** with an open formula
- 🧥 Actionable advice for clothes, rain, wind, shoes and sun
- 📍 Open-Meteo by geolocation or selected city — no API key
- 🌓 Light/dark themes with persistent preferences
- 🏗️ Clean `data → domain → presentation → UI` boundaries
- 🧪 JVM-testable domain rules, cache and graceful recovery
- ⚙️ Android CI, contributor docs, security policy and MIT license
